### Как я работаю

- Сначала уточняю задачу и показываю план, потом пишу код
- Код проверяю автотестами, а результат — вживую вместе с заказчиком
- Пароли и ключи храню отдельно от кода, персональные данные обрабатываю по **152-ФЗ**
- Оставляю инструкцию по запуску: проект можно передать другому разработчику
